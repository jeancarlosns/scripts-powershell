# PowerShell Scripts Repository 📜⚡

Bem-vindo ao meu repositório de scripts PowerShell! Aqui você encontrará uma coleção de scripts úteis para automação e gerenciamento de diversos ambientes e ferramentas, como **Exchange Online**, **Microsoft 365**, **Azure**, e muito mais.

## 📂 **Conteúdo**
### Este repositório inclui:
- **Scripts para Exchange Online**:
  - Automação de relatórios de caixas de e-mail.
  - Gerenciamento de políticas e permissões.
  - Exportação de dados em formatos úteis como `.csv`.
- **Scripts para Microsoft 365**:
  - Configuração de usuários e grupos.
  - Auditoria e relatórios.
  - Gerenciamento de licenças e serviços.
- **Scripts Gerais**:
  - Soluções para monitoramento e análise.
  - Automação de tarefas administrativas.
  - Scripts personalizados para aumentar a produtividade.

## 📜 **Pré-requisitos**
Para usar os scripts deste repositório, certifique-se de:
- Ter o **PowerShell** instalado (versão 5.1 ou superior, preferencialmente **PowerShell Core**).
- Ter acesso às APIs ou credenciais apropriadas (por exemplo, módulos como `ExchangeOnlineManagement` ou `AzureAD`).
- Seguir as instruções específicas de cada script, que estarão nos comentários internos do código.
